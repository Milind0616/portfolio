## ✨ About The Project

A stunning, automotive luxury-inspired portfolio website built with **React** and **Framer Motion**. This portfolio showcases a distinctive BMW M4-themed design with high-performance animations, parallax effects, and an immersive user experience inspired by luxury automotive engineering.

### 🎯 Key Highlights

- 🚗 **BMW M4 Background** - Real car image with parallax scrolling and dynamic zoom effects
- ✨ **Framer Motion Animations** - Smooth, staggered page transitions with spring physics
- 🎨 **Premium Design System** - Metallic silver (#C0C0C0), deep blue (#1E3A8A), and sharp red (#DC2626)
- 🔤 **Distinctive Typography** - JetBrains Mono (all typography)
- 📱 **Fully Responsive** - Optimized for all devices from mobile to 4K displays
- ⚡ **Performance Optimized** - GPU-accelerated animations and lazy loading

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v14 or higher)
- **npm** or **yarn**

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Milind0916/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm start
   ```

4. **Open in browser**
   ```
   http://localhost:3000
   ```

### Build for Production

```bash
npm run build
```

Creates an optimized production build in the `build/` folder.

## 🎨 Customization Guide

### Change Color Scheme

Edit `src/index.css`:

```css
:root {
  --color-metallic-silver: #C0C0C0;  /* Primary text */
  --color-deep-blue: #1E3A8A;        /* Accent blue */
  --color-sharp-red: #DC2626;        /* Highlights */
  --color-dark-bg: #0A0A0A;          /* Background */
}
```

### Update Personal Information

| File | Content |
|------|---------|
| `Hero.js` | Name, tagline, stats |
| `Skills.js` | Technical skills & metrics |
| `Projects.js` | Portfolio projects |
| `Experience.js` | Work experience & education |
| `Contact.js` | Email, phone, social links |

### Add BMW Background Image

Save your BMW image as `bmw-m4.jpg` in the `public/` folder.
